## Replacing with real venue photography

Each `<div class="plate">` / `<div class="frame-plate">` in `v2.html` carries an inline
`style="background-image:url('assets/images/<file>.jpg')"`. To swap in a real photo, replace the file
at that path (keep the same filename) or update the `url(...)` value — no other markup changes needed.
